## A. 인증·초대·프로필
운영자 생성 CLI, 초대 발급/폐기·기본7일 만료·가입/기존 계정 참여, 로그인/로그아웃, 현재 사용자. 최대 활성10명은 트랜잭션 검사. 비밀번호는 Argon2 등 검증된 해시, JWT 액세스 토큰 + 갱신 쿠키 HttpOnly/SameSite/운영Secure, CSRF·Origin 검사·속도 제한·소속/소유권 검사. 초대 코드는 생성 시 한 번 표시, DB 해시 보관. 테스트 계정은 테스트 DB 전용.
마이페이지: 표시 이름2~20자, 소개160자 이하, 전체 Unicode 이모지 선택, 기본 공부/휴식 설정, 기존 비밀번호 확인 후 변경, 로그아웃. 평문 비밀번호 노출 금지.

## B. 세션과 보상 — 누적 방식 구현 금지
기본60/10분, 공부20~180분 정수·휴식1~60분. 시작 전 수종 선택, 시간에 따른 크기 자동 미리보기. 50분 미만 small, 50분 이상 large. 필요한 칸 수 floor(설정분/20).
20분→1작음, 40분→2작음, 49분→2작음, 50분→2큼, 60분→3큼, 180분→9큼. 나머지 분은 다른 세션에 이월하지 않습니다. 성공 집중 통계는 성공한 목표 시간 전체입니다. 30분 두 세션은 나무2그루이지3그루가 아닙니다.
시작 시 서버가 수종·목표·서로 다른 빈 좌표 N개를 검증하고 세션+칸 예약을 원자적으로 생성합니다. 한 세션은 한 구역/한 수종. 6×6 구역이 부족하면 시작 전 구역 추가. 두 탭/기기에서 중복 시작 금지. 수종·목표·위치는 시작 뒤 수정 불가. 나무 이동/수납 API를 만들지 마세요.
초기에는 예약 칸에 묘목. 정상 완료 시 N개 나무 확정. 중간20분 지급은 없습니다. pause는 실제 구간을 닫고 유지, resume는 새 구간을 열어 이어갑니다. 현재 세션 중도 포기는 확인 다이얼로그 후 인정시간0·성공나무0, 예약 칸 모두 회색 시든 나무로 고정. 이전 완료 세션은 그대로 보존. raw 경과는 진단용으로만 보관하고 성공 집중 통계에 넣지 않습니다. 시든 나무 이동/부활/수납 없음.
서버 시각·구간·DB 워커가 권위입니다. UI interval만으로 지급 금지. 목표 종료 시각 이후 완료가 포기보다 우선, 초과 적립 금지. 새로고침/백그라운드/서버 재시작 후 복원. request ID·버전·행 잠금·DB unique로 중복 완료/보상 방지. 테스트용 강제 완료 버튼을 운영 코드에 넣지 마세요.
도서관 보너스는 단계2에서 연결합니다. session.library_at_start 필드를 마련하되 이번 단계 실제 미판정이면 false로 표시하고 예시 IP로 인정시키지 마세요.

## C. 대시보드와 숲
왼쪽 타이머, 오른쪽 수종6종·크기/개수 미리보기·고정 개인 숲. ui/assets/trees의 36개 소스를 사용. ForestGrid는 시작 전 선택만, API 성공 후 locked. 선택칸 부족·이미 점유·저장 실패·동시 충돌 상태. 별도 내 숲 페이지 없음.
일시정지/재개/포기, 정상 완료/휴식 수동 시작, 화면 종료 토스트. 모든 시각 효과만, audio/진동/OS notification API 금지. reduced-motion 대응. 360px에서 숲 타일 직접 입력.

## D. 기본 날짜별 기록
오늘 목표 CRUD와 완료 체크, /records/:date에 계획 텍스트·실제 기록·공개 토글(기본 비공개), 수정/조회·권한 검사. 공개는 같은 스터디에 해당 날짜 계획/목표/기록/시간표를 공유한다는 안내. 이번에는 서버 공개 필터까지 구현하고 피드는 단계2에서 연결하세요. 주간 회고·WBS 전체·시간표 드래그는 단계3 체크리스트에 남깁니다.
시간은 UTC 저장·Asia/Seoul 집계, 자정 집중 구간 분할. 데모 데이터를 실제 통계와 섞지 마세요. 캘린더/공동 숲 등 미완성 메뉴는 준비 중이라고 명확히 표시하거나 숨기세요.

## E. 검증
순수 정책 경계20/40/49/50/60/180 및 이월 없음, 중도 포기0/이전 기록 유지, pause 제외, 경합 완료 우선, 중복 완료 무해, 정확한 칸 수/고유 좌표/이동 금지, 타인 정보/비공개 기록 차단, 초대10명/11번째 거부, 프로필 저장, CSRF/로그아웃, UTC→한국 자정. 주입 시계로 테스트하고 실제 분 대기 금지.
Playwright로 로그인→수종·칸 선택→시작·pause·resume→완료 또는 포기→새로고침 복원→일일 기록 공개 변경을 검증. 1440/1280/390/360 화면, 키보드, 폰트 로드, npm build/lint/backend tests. 실행하지 않은 것은 미실행이라고 기록하세요.
커밋 예: feat: implement session based fixed forest workflow. 단계2·배포·push는 진행하지 마세요.

## v5 집중 화면·인증 수정 — 최우선 구현 지침
1. D-day는 시험까지 / D-n / 시험일을 한 줄로 배치, 줄 사이 여백 제거.
2. 시작 API 성공 후 /focus/:sessionId로 이동. 메뉴를 숨기고 서버 경과 시간에 따라 나무 성장 애니메이션. pause는 성장 중지. 다른 내부 페이지로 이동 시 취소/포기 확인, 서버 abandon 성공 후 이동. 브라우저 종료의 완전 감지/차단은 보장하지 않는다. 외부 교재 탭 전환을 실패로 취급하지 않음.
3. 초대 기반 이메일·실명·비밀번호 회원가입/로그인, 운영자 승인 상태를 도입. 실명은 본인/운영자만 조회하고 광장은 표시 이름 사용.
4. 서버 세션 쿠키 인증 대신 access JWT(15분, 메모리 Bearer)+refresh opaque token(7일, HttpOnly/Secure/SameSite cookie, DB 해시)로 교체. rotation/재사용 차단/로그아웃 폐기·서명과 claims 검사·CSRF/Origin 검사. JWT_SECRET은 서버 .env, 브라우저 저장소에 토큰 저장 금지.
5. 상세 정책·API·검증은 docs/10-focus-and-jwt.md가 기존 인증 지침보다 우선. 단계1에 로그인·가입·승인 게이트·JWT 갱신·집중 전용 페이지·이탈 guard까지 구현. UI 시안은 서버/인증을 구현하지 않으며 입력 자격 증명을 저장하거나 가짜 JWT를 만들지 않음.
6. PomodoroView.jsx는 표시 전용 컴포넌트. 부모가 서버 시간·상태·이탈 확인을 연결하고 디자인 preview.css의 focus/growth 스타일을 앱 스타일로 분리한다. 시안의 60배속/즉시 완료는 운영에 포함하지 않는다.
