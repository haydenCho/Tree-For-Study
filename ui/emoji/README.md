# 이모지 데이터
Unicode Emoji 18.0의 fully-qualified 항목과 component 총 3972개를 포함합니다. 피부색·성별·국기·ZWJ 조합을 보존하며 중복 표현인 minimally-qualified/unqualified는 제외합니다. 일부 새 이모지는 운영체제에서 지원하지 않아 빈 사각형 등으로 보일 수 있습니다.
한국어 이름/검색어는 Unicode CLDR ko.xml에서 가져왔습니다. 한국어가 없는 새 항목은 영문명을 표시합니다. 수집일 2026-10-16. 원본 파일과 Unicode License v3를 함께 배포합니다.
Windows/Notion 자체 아이콘·커스텀 업로드 이미지·스티커를 복제한 세트가 아니라 표준 Unicode 이모지 문자 전체입니다. 표시 글꼴은 Segoe UI Emoji / Apple Color Emoji / Noto Color Emoji 등 시스템 글꼴입니다.
검색은 한글·영문·이모지·코드 포인트, 카테고리별 페이지 탐색은 120개 단위. 전체 항목이 다음/이전 페이지를 통해 선택 가능합니다. 브라우저와 서버에서 전체 문자열을 한 항목으로 검증해야 하며 문자열 첫 코드 포인트만 저장하면 안 됩니다.
