스터디 2026-10-20~11-19, 시험 11-20. 화·수·목·금 10:00~16:00 대면, 주말 보충, 월요일도 자율 기록 가능. 총 19회, 예정 체류 114시간(휴식 포함). 시간대 Asia/Seoul, DB 시각 UTC. 휴관일은 운영자가 휴무로 지정. 시험일까지 D-day, 이후 시험 종료 표시. 기간 종료 이후 조회·기록 수정은 가능, 새 집중 세션은 제한한다.

## 2. 화면과 동선
메뉴: 대시보드 / 공동 숲 / 캘린더 / 기록 / 마이페이지. 별도 내 숲 페이지 없음.
- 대시보드: 좌측 타이머, 우측 개인 숲·수종 선택·예약 칸. 오늘 목표·출석·멤버 요약·다음 일정. 세션 시작 준비가 한 화면에서 완료된다.
- 공동 숲: 스터디 전체 대시보드인 광장. 공동 숲, 최대 10명 카드, 공개 일일 기록·주간 회고, 오늘 활동 요약. 팀원 카드 클릭으로 해당 팀원의 공개 WBS를 표시한다.
- 캘린더: 월간 날짜 + WBS 목록/일정 막대. 날짜 클릭은 /records/YYYY-MM-DD로 이동. WBS 막대의 작업 선택과 날짜 이동 동작을 구분한다.
- 기록: 선택 날짜의 오늘 계획·실제 공부 기록·드래그 시간표·공개 설정. 기존 주간 회고와 주말 보충도 유지한다.
- 마이페이지: 표시 이름·소개·아바타(전체 Unicode 이모지)·기본 공부/휴식 시간·비밀번호 변경·로그아웃. 사용자 업로드 프로필 사진은 후속 확장, 초기에는 전체 Unicode 이모지 선택.

## 3. 집중과 보상 — 세션 단위
기본 공부 60분·휴식 10분(제안값). 공부 설정 20~180분 정수, 휴식 1~60분. 20분 미만 세션은 초기 버전에서 시작하지 못하게 한다(제안). 수종 하나를 선택하고 설정 시간에 따른 크기를 미리 확인한다. 크기를 시간과 무관하게 고르는 기능은 없다.

| 성공한 세션 | 나무 | 크기 |
|---|---|---|
| 20분 | 1 | 작음 |
| 40분 | 2 | 작음 |
| 49분 | 2 | 작음 |
| 50분 | 2 | 큼 |
| 60분 | 3 | 큼 |
| 80분 | 4 | 큼 |

count=floor(target_seconds/1200). size=large if target_seconds>=3000 else small. 문장 중 50분 기준이 겹치므로 '50분 이상은 큰 나무'를 적용한다. 50분의 남은 10분처럼 보상 단위 미만 시간은 다음 세션으로 이월하지 않지만, 정상 완료 세션의 공부 시간 통계에는 전체 50분을 기록한다.
세션 사이 누적 보상·잔여 포인트 원장은 폐기. 30분 성공 + 30분 성공은 작은 나무 2그루이며 60분 1회 성공은 큰 나무 3그루다. 짧게 쪼개기와 길게 공부하기의 결과가 다르다.
시작 전 예상 개수만큼 빈 칸 선택 → 시작 요청에서 수종·목표 시간·좌표 모두 서버 검증 → 하나의 트랜잭션으로 세션 생성·칸 예약. 60분이면 3칸, 180분이면 9칸. 전체 6×6 구역에 여유가 없으면 시작 전에 새 구역을 추가하고 한 구역 안에서 필요한 칸을 선택한다. 시작 전에는 선택 해제 가능, 시작 이후 수종·시간·위치 수정 불가.
성공 시 예약 칸의 묘목을 선택 수종/크기의 나무로 확정. 20분 경과마다 중간 지급하지 않는다. 세션 전체를 정상 완료했을 때 일괄 확정하여 중도 포기와 충돌하지 않게 한다. 화면에서 성장 진행 효과는 보여줄 수 있으나 성공 기록은 아니다.

## 4. 세션 상태·중도 포기
ready → focusing ↔ paused → completed 또는 abandoned. 휴식은 별도 resting/rest_completed/rest_ended. 사용자당 활성 타이머는 하나, paused도 활성 상태다.
일시정지 중 시간은 제외하고 재개 가능, 시들지 않는다. 중도 포기 버튼은 '이번 세션 시간은 초기화되고 예약한 나무가 시듭니다' 확인 다이얼로그 후 처리한다. 포기 시 현재 세션 인정 집중 시간 0, 성공 보상 0, 모든 예약 묘목은 회색으로 시든 나무가 된다. 이전 완료 기록은 유지한다. 시든 나무는 개인 숲의 고정 칸에 남고 이동·수납·부활 없음(제안). 성공 그루 수/공동 숲에서 제외, 별도 포기 이력에는 남는다.
원시 경과 초는 세션 진단/이력에 보관하되 공식 집중 통계·공동 기여·주간 집중 합계에 포함하지 않는다. 타이머 화면은 설정 시간으로 초기화. 시간표에 사용자가 쓴 활동 기록은 별도 메모이므로 자동 삭제하지 않으며 공식 집중 시간과 구분한다.
서버가 집중 구간과 목표 완료 시각을 계산한다. pause 시 구간 종료, resume 시 새 구간. 브라우저 interval은 표시 용도. 새로고침·탭 숨김·화면 잠금 자체는 포기가 아니다. 예정 시각 후에는 더 적립하지 않으며 정상 완료와 포기 요청이 경합하면 서버 시각상 이미 목표에 도달한 세션은 완료가 우선이다.
오프라인은 서버 시작/일시정지/포기 조작 불가, 오류를 표시한다. 연결이 끊긴 기존 세션은 정해진 목표까지 진행하고 재접속 복원. DB 기반 만료 처리 워커, 재시작 복구, 요청 ID/버전/행 잠금으로 중복 완료·다중 예약 방지. 완료 상태와 나무 확정은 원자적 처리.

## 5. 수종·디자인
6종: 둥근 참나무, 층층 전나무, 분홍 벚꽃, 황금 은행, 늘어진 버드나무, 꽃송이 정원수. 종류는 시작 전 선택. 각각 작은/큰 원본, 일반/도서관/시듦 상태 제공. 작은 나무는 단순 축소뿐 아니라 수관 분기와 잎/꽃 밀도를 줄이고 큰 나무는 풍성한 수관으로 표현한다.
도서관형은 같은 수종에 금빛 화환·꽃·버섯·별 장식을 더한다. 시듦은 회색 수관과 기울어진 모습, 시든 상태 텍스트로 표시한다. 색상만으로 구분하지 않는다. 기본 숲 팔레트는 #4F6547/#D58C36/#899078/#DED9CB/#49382D, 꽃 수종에는 분홍/크림 보조색 사용. 2.5D 고정 시점, 회전 없음. 폰트 Pretendard, 파일 자체 호스팅 및 OFL 동봉.

## 6. 도서관 보너스
세션 생성 요청의 서버 검증된 클라이언트 공인 IP가 운영자 등록 목록과 일치하면 library_at_start=true로 고정한다. 시작 이후 다른 네트워크 이동, 휴식, 종료 IP, 인정 시간 비율은 고려하지 않는다. 재개를 새로운 시작으로 간주하지 않는다. 해당 세션이 성공하면 모든 나무에 도서관 장식, 포기하면 회색 시듦 상태만 적용한다.
등록 IP는 IPv4/IPv6 정확한 주소 여러 개를 기본 지원. CIDR는 실제 도서관 소유 범위를 확인한 경우만 운영자 설정. 일반 사용자 가입/시작 화면에는 도서관 인식 여부만 표시한다. IP 진단 API는 운영자만 접근하고 캐시 금지. 시작 전 UI 표시는 참고이며 시작 요청에서 다시 판정한다.
프록시: 사용자 → EC2 Caddy(HTTPS) → FastAPI → DB. Caddy가 전달한 실제 접속 IP를 FastAPI가 신뢰된 Caddy 연결에서만 읽는다. 임의 클라이언트의 X-Forwarded-For를 직접 신뢰하지 않는다. backend/db 포트 외부 비공개. CDN/ALB 추가 시 프록시 체인 재설정 필요. 상세는 docs/05-library-ip.md.

## 7. 출석·멤버·정원
정원 최대 10명, 활성 멤버 수 트랜잭션 검사. 초대 유효기간 기본 7일, 해시 저장·폐기·만료 지원. 운영자 CLI 생성, 비밀번호 해시·JWT 액세스 토큰 인증.
출석 상태는 미체크인/출석/결석/휴무/자율일. 지각 상태·유예 시간·지각 통계 모두 없음. 예정일 내 언제 체크인해도 출석. 자율 참여에 맞춰 당일 23:59:59 한국 시간까지 체크인 허용, 다음 날 00:00에 미체크인만 결석으로 확정(제안). 휴무는 분모 제외. 출석 정정은 운영자 사유 기록. 결석으로 나무 차감 없음.
집중 상태와 온라인 상태는 별개. 15초 polling, 30초 heartbeat, 90초 이후 연결 확인 불가 표시. 백그라운드 지연으로 공부를 취소하지 않는다. 상태 표시는 공부 중/휴식/일시정지/대기이며 비공개 공부 제목은 노출하지 않는다.

## 8. 날짜별 계획·기록·시간표
/records/:date에 오늘 계획 텍스트와 체크 목표, 오늘 기록 본문, 시간표, 공개 토글을 제공한다. 달력 날짜에서 진입 시 해당 날짜를 제목에 표시한다. 기록 작성일과 대상 날짜를 구분한다.
시간표는 한국 시간 하루 00:00~24:00을 15분 단위로 표현. 초기 스크롤은 09:00 근처. 시작 칸에서 끝 칸까지 드래그 → 공부 제목/메모/계획 또는 실제 기록 종류 → 저장. 기존 블록은 이동/끝 조절 가능하되 종료>시작, 날짜 범위와 15분 스냅 검증. 같은 레이어 내 중복 시간은 거부하고 계획/실제 레이어끼리 겹침은 허용. 날짜 넘는 블록은 자정에서 분리(초기 직접 한 날짜씩 작성). 최소 15분, 24:00은 종료만 허용.
키보드·터치 대안으로 시작/종료 시각 폼 제공. 드래그 threshold를 두어 클릭과 드래그를 구별하고 pointer capture/취소 시 복구. 기록 수정은 날짜별 권한 검증. 시간표는 계획·자기 기록이며 집중 보상 원장과 독립. 수동 기록을 추가해도 나무를 지급하지 않는다.
일일 기록의 공개 여부 기본 비공개. 공개 범위는 동일 스터디 회원에게만, 인터넷 공개가 아니다. 공개하면 해당 일일 기록의 계획·목표·실제 기록·시간표를 함께 공유한다는 설명을 표시한다. 특정 비밀 메모를 따로 공유하려면 해당 일일 기록을 비공개로 유지한다. 비공개 전환/삭제 시 광장 피드와 타인 API에서 즉시 제외한다.

## 9. 캘린더·WBS
월간 캘린더는 10/20~11/19 기간의 대면/자율/휴무 표시와 날짜별 계획 수를 제공. 날짜 링크는 일일 기록으로 이동. WBS는 상위 과제/하위 작업(최대 2단계), 제목, 시작일·종료일, 상태(예정/진행/완료), 진행률, 메모, 공개 여부를 가진다. 예: AWS SAA → VPC 개념/문제/오답.
WBS의 날짜 범위는 일 단위이며 종일 날짜를 포함한다. 종료>=시작, 자식은 부모 범위 내, 진행률 0~100. 일정 막대는 조회용으로 시작하고 생성·편집은 명확한 폼으로 구현한다. WBS 자체의 막대 드래그 편집은 필수가 아니고 시간표 드래그는 필수이다.
팀원 카드 → /calendar?member=id → 공개 WBS만 읽기 전용. 행별 공개를 사용하며 비공개 부모의 이름은 노출하지 않고 공개 자식은 독립 행으로 표시. 팀원 캘린더 날짜 클릭은 해당 팀원의 공개 일일 기록(/members/:id/records/:date)으로 이동. 비공개 날짜는 '공개된 기록 없음'만 반환한다. 제목/메모/집계로 비공개 내용을 추정시키지 않는다.

## 10. 공동 숲 = 광장
상단 전체 성공 집중 시간·성공 나무·출석 요약. 가운데 공동 숲, 팀원 카드 4~10개, 공개 일일 기록과 공개 주간 회고 피드. 순위 경쟁 없음.
공동 숲은 정상 완료 나무만 사용. 개인 좌표와 별개로 서버가 빈 칸을 무작위 선택하여 저장한다. 새로고침마다 재추첨하지 않는다. 6×6 한 구역이 차면 새 구역 생성. DB 고유 제약·잠금으로 겹침 방지. 사용자/운영자 모두 공동 나무 수동 이동 기능 없음.
나무 hover/focus/click/tap 시 소유자의 표시 이름·아바타·소개·공개 WBS 링크를 카드로 표시. 마우스 전용 정보 금지, Escape/닫기로 해제. 이메일·계정 ID·접속 IP·비공개 제목은 카드에 노출하지 않는다. 공개 기록 피드에서 선택 날짜의 공개 기록 상세를 열 수 있다.

## 11. 유지 기능·프로필·알림
주말 보충은 미완료 목표를 선택해 토/일로 이월, 원본 링크 유지, 동일 대상일 중복 방지. 주간 회고의 '잘한 점/어려웠던 점/다음 주 계획' 유지, 기본 비공개·별도 공개 토글. 주간 합계는 성공한 집중 세션만 집계, 자정 구간은 날짜별 분할.
마이페이지에서 표시 이름(2~20자), 소개(최대 160자), 제공 아바타, 기본 타이머 설정 수정. 타인 프로필 편집 불가, 소개는 텍스트로 렌더링. 공개 카드에 즉시 반영. 비밀번호 변경은 기존 비밀번호 확인 후 처리, 화면/로그에 평문 노출 금지.
소리 옵션·오디오 API·진동 전부 제거. 시각적 토스트·진행 표시·완료 배지·회색 시듦 전환만 사용. 깜빡임·강한 섬광 금지, reduced-motion에서 전환 최소화.
OS Web Push는 운영체제가 소리를 낼 수 있어 '시각 효과만'을 확실히 지킬 초기 범위에서 제외한다. 화면이 숨겨지면 탭 제목/앱 배지와 복귀 시 토스트를 사용하되 잠금/백그라운드에서 정시 표시를 보장하지 않는다. OS 알림을 다시 추가하려면 별도 사용자 결정 필요. 서버 완료 워커는 알림 유무와 무관하게 유지한다.

## 12. 보안·운영·데이터
비밀은 .env, .env.example은 빈 값 또는 placeholder. VITE_*는 공개되므로 서버 키/DB 비밀번호 넣지 않음. 메모리 JWT 액세스 토큰 + HttpOnly/Secure/SameSite 갱신 쿠키·CSRF·Origin 검사·로그인 속도 제한. 회원/소유권/공개 필터는 모든 읽기·쓰기 API 서버에서 검증. 로그에 세션 토큰·비밀번호·일일 기록 본문·IP를 불필요하게 남기지 않는다. DB 외부 비공개·HTTPS·일일 외부 백업·복원 확인.
주요 테이블: users, auth_token_sessions, studies, memberships, invites, study_dates, attendance, focus_sessions, focus_intervals, session_plots, tree_catalog, trees, personal_zones, community_zones, community_placements, goals, daily_entries, timetable_blocks, wbs_tasks, weekly_reviews, library_networks, audit_events. 이전 reward_allocations/수납함/이동 API/푸시 예약 모델은 사용하지 않는다.
focus_sessions: target_seconds, species, size, library_at_start, network_rule_version, status, credited_seconds, observed_seconds, version. session_plots는 소유자·구역·좌표 고유, 시작 시 예약하고 성공/포기해도 위치 고정. trees(session_id,ordinal) 고유. 공동 배치(구역,row,col)와 tree_id 고유. WBS·일일 기록 공개 필터를 소속 확인 후 적용.
API 초안: POST /api/sessions (species,targetSeconds,plots,requestId); POST /api/sessions/:id/pause,resume,abandon; GET /api/dashboard; GET /api/plaza; GET/PUT /api/daily-entries/:date; CRUD /api/timetable-blocks; CRUD /api/wbs; GET /api/members/:id/wbs; GET /api/members/:id/daily-entries/:date; GET/PATCH /api/me/profile; POST /api/attendance/check-in; GET /api/admin/network-diagnostic. 성공 완료는 서버 처리, 운영용 강제 보상 API 없음.

## 13. 완료 기준
PC 1440/1280, 모바일 390/360 검수. 접근성·에러·빈 상태 포함. 10명 가입·동시 예약, 40/50/60분 보상, 중도 포기/일시정지/복원, 공개 전환, 시간표 드래그, WBS 날짜 이동, 도서관 시작 판정 검증. 개발은 단계별 사용자 검수와 커밋, push는 사용자만. 10/20 사용 시작 목표이지만 추가 기능으로 일정이 빠듯해졌으므로 구현 완료를 보장하지 않는다. 누락 기능은 임의 삭제하지 말고 단계 체크리스트에 남긴다.

## v5 집중 화면·인증 수정 — 최우선 구현 지침
1. D-day는 시험까지 / D-n / 시험일을 한 줄로 배치, 줄 사이 여백 제거.
