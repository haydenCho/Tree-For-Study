# 단계별 개발 계획 v5

추가 기능을 반영한 목표 일정이며 완료 보장은 아니다. 각 단계 검수 후 다음 프롬프트로 진행. Claude Code는 명시적으로 지시된 단계까지만 구현한다.

| 단계 | 목표 | 범위 | 완료 확인 |
|---|---|---|---|
| 0 | 10/16 | 디렉토리/문서/환경/Compose·React·FastAPI·Postgres | health/ready·시크릿 제외 |
| 1 | 10/17 | 초대·인증·프로필·대시보드 세션·고정 배치·기본 일일 기록 | 20분 규칙·50분 경계·포기·재접속 |
| 2 | 10/18 | 출석·도서관 시작 IP·공동 광장·공개 WBS 조회 | 10명·권한·무작위 배치·프록시 |
| 3 | 10/18~19 | 캘린더/WBS CRUD·드래그 시간표·보충·주간 회고 | 날짜 라우팅·공개 전환·모바일 |
| 4 | 10/19 | EC2/HTTPS·백업·통합 검수 | 재시작·복원·동시성·무음 |
| 운영 | 10/20 | 스터디 시작 | 미완료 범위 명확히 공유 |

2단계 공개 WBS 조회에 필요한 최소 모델은 2단계에 준비하고 전체 편집 UI는 3단계에 완성한다. 범위를 축소해야 하면 사용자에게 미완료·출시 영향을 보고하고 임의로 기능을 삭제하지 않는다.

## 저장소 구조
frontend/src/{app,components,features,lib,styles}, frontend/public/assets 및 fonts.
backend/app/{api,core,models,schemas,services,workers}, backend/migrations, backend/tests.
docs/{product,design,architecture,development,operations}, prompts, infra/caddy, compose.yaml, compose.production.yaml, .env.example, CLAUDE.md, README.md.
frontend는 React JavaScript Vite, backend는 FastAPI/Uvicorn/Pydantic/SQLAlchemy/Alembic, DB PostgreSQL. 10명은 polling으로 충분, 초기 Redis/WebSocket/3D 엔진 불필요.

## 환경과 보안
DATABASE_URL, POSTGRES_PASSWORD, JWT_SECRET는 서버 .env의 비밀. APP_ORIGIN, COOKIE_SECURE, TRUSTED_PROXY_IPS는 서버 설정. VITE_API_BASE_URL=/api는 공개 설정. 비밀을 VITE_*에 넣지 않음. Web Push/VAPID·오디오 패키지 불필요. DB/백엔드 외부 직접 포트 비공개, Caddy만 80/443. .env.example placeholder, 기존 .env 보존. 폰트 자체 호스팅 및 라이선스 유지.

## 필수 테스트
1. 20→1작음, 40→2작음, 49→2작음, 50→2큼, 60→3큼, 180→9큼.
2. 30분 두 성공은 2그루; 이월 없음. 중도 포기 59분은 성공시간0/나무0, 이전 성공 기록 유지.
3. pause는 경과 제외, resume는 수종/크기/IP 판정/예약 위치 유지.
4. 시작에 정확한 개수의 서로 다른 빈 칸 필요. 두 탭 경합 중 하나만 성공. 시작 후 이동 API 없음.
5. 완료/포기 경합에서 서버 완료시각 판정. 중복 요청·워커 재시작에서 나무 중복 없음.
6. 시작 IP 일치 후 종료 IP 불일치해도 장식. 반대는 장식 없음. 전달 헤더 위조 거부.
7. 정원 10명 원자적 검사, 11번째 거부. 하루 종료 후 결석, 지각 enum 없음.
8. 일일 기록/WBS 공개를 비공개로 바꾸면 타인 API/광장/캐시에서 사라짐. 비공개 부모 이름 노출 없음.
9. 캘린더 날짜→정확한 일일 기록; 드래그 시간표 스냅/역방향/겹침/수정/폼 대안.
10. 공동 숲 배치는 최초 무작위, 새로고침 안정, 칸 경합 고유 제약. hover/focus/tap 소유자 일치.
11. Playwright: 설정→수종·칸 선택→시작→정상 완료/포기→광장→공개 기록→팀원 WBS.
12. 1440/1280/390/360 및 키보드, 오디오·진동 호출 없음.
실제 분 대기 대신 주입 가능한 테스트 시계 사용. 운영용 강제 완료/시간 조작 API 금지.

## v3 추가 변경 — 2026-10-16
- 대시보드 카드 높이 자동 늘림 제거, 타이머 가로형으로 축소, PC 숲 최대 폭320px, 요약 카드는 짧은 바로가기로 압축. 칸 목록은 제거하고 숲에서 직접 선택. 작은 화면은 순서대로 세로 배치.
- 황금 은행은 둥근 참나무/벚꽃과 같은 둥근 수관에 부채꼴 은행잎을 부착. 작은/큰·일반/도서관/시듦 여섯 변형 모두 갱신.
- 아바타는 Unicode Emoji 18.0의 canonical fully-qualified+component 전체 3,972개 선택. 카테고리·한글/영문 검색·120개씩 페이지 이동. 국기·성별·피부색·ZWJ 문자열을 보존. Windows/Notion 고유 스티커나 업로드 이미지는 범위 밖이며 시스템 기본 이모지 글꼴로 표시. 플랫폼별 지원/모양은 다를 수 있음.
- 한글 검색어는 Unicode CLDR, 영문명은 emoji-test 데이터. 원본·라이선스·버전 포함, 오프라인 사용 가능. 프로필 저장 전에 이모지 하나가 목록에 존재하는지 검증; 서버도 동일 allowlist로 검증. 글자 하나로 잘라 저장하지 않음.
- React EmojiPicker.jsx, emoji-data.json, CSS를 함께 제공. 선택은 초안만 갱신하며 프로필 저장 버튼으로 확정.

## v4 레이아웃 수정 — 2026-10-16
- 모든 화면의 공통 헤더 제거. D-day는 PC 좌측 사이드바에 표시, 모바일에서는 하단 내비게이션 영역 상단의 작은 줄로 유지. 페이지 제목은 본문에 남김.
- 칸 목록 버튼·다이얼로그·React 대체 목록 삭제. 숲의 실제 빈 칸을 클릭/터치하거나 키보드 Tab·Enter로 직접 선택. 수종/위치 고정 정책은 유지.
- 공동 숲은 숲 최대 폭과 팀원 카드 높이를 줄이고 공개 피드를 압축. 멤버가 많을 때 목록 영역 안에서 스크롤.
- 캘린더 날짜 셀과 WBS 카드 간격 축소. 작업 추가 폼은 접기/펼치기로 필요한 때만 표시.
- 기록 페이지의 편집 필드·시간표 높이·주간 회고·주말 보충 간격 축소. 데스크톱은 2열 본문과 3열 회고, 작은 화면은 세로 배치. 전체 내용을 숨기거나 기능을 삭제하지 않음.
- 최신 납품본은 v4. 과거 변경 로그의 칸 목록 요구는 이 변경으로 폐기. 코드·디자인·Claude Code 지침 모두 최신 규칙 적용.

## v5 집중 화면·인증 수정 — 최우선 구현 지침
1. D-day는 시험까지 / D-n / 시험일을 한 줄로 배치, 줄 사이 여백 제거.
2. 시작 API 성공 후 /focus/:sessionId로 이동. 메뉴를 숨기고 서버 경과 시간에 따라 나무 성장 애니메이션. pause는 성장 중지. 다른 내부 페이지로 이동 시 취소/포기 확인, 서버 abandon 성공 후 이동. 브라우저 종료의 완전 감지/차단은 보장하지 않는다. 외부 교재 탭 전환을 실패로 취급하지 않음.
3. 초대 기반 이메일·실명·비밀번호 회원가입/로그인, 운영자 승인 상태를 도입. 실명은 본인/운영자만 조회하고 광장은 표시 이름 사용.
4. 서버 세션 쿠키 인증 대신 access JWT(15분, 메모리 Bearer)+refresh opaque token(7일, HttpOnly/Secure/SameSite cookie, DB 해시)로 교체. rotation/재사용 차단/로그아웃 폐기·서명과 claims 검사·CSRF/Origin 검사. JWT_SECRET은 서버 .env, 브라우저 저장소에 토큰 저장 금지.
5. 상세 정책·API·검증은 docs/10-focus-and-jwt.md가 기존 인증 지침보다 우선. 단계1에 로그인·가입·승인 게이트·JWT 갱신·집중 전용 페이지·이탈 guard까지 구현. UI 시안은 서버/인증을 구현하지 않으며 입력 자격 증명을 저장하거나 가짜 JWT를 만들지 않음.
6. PomodoroView.jsx는 표시 전용 컴포넌트. 부모가 서버 시간·상태·이탈 확인을 연결하고 디자인 preview.css의 focus/growth 스타일을 앱 스타일로 분리한다. 시안의 60배속/즉시 완료는 운영에 포함하지 않는다.
